# 03 · PV分镜草案——仅用于组织素材，供用户审查

**这不是剪辑定稿，也不是已完成PV。** 下面的约65秒只是说明素材密度与先后关系，用户尚未决定时长、画幅、语言、配乐、片名和CTA。当前没有制作剪辑、配音或音乐成品。

## 一句话方向

让观众先看懂“真的能经营一家AI公司”，再让每次管理选择引爆一个圈内梗；不是把十几个社交媒体截图依次贴上去。叙事主轴为：**成立公司 → 招聘人才 → 模型开发 → 发布 → 业界反应 → 登顶与继续迭代**。

## 本轮统一假设（均可由用户改）

- 暂用虚构公司 **星屑智能 / STARDUST AI**、模型 **S1**；不将夸张剧情安到真实公司或个人头上。样图出现的文字/数值都是构图占位，不代表设定已定。
- 角色识别：白衬衫创始人、黑连帽衫工程师、少量通用员工/同行。人物照片仅作可选资料，不在本轮样图中复制真人身份。
- 画面基于《游戏发展国》PC版参考：木色小办公室、斜俯视、微型像素员工、蓝银大弹窗、顶部日期资金、底部经营指标。保留“像素场景+高清UI文字”混排。
- 字幕草案为中文；样图中的按钮主要是短英文占位。最终是否中文UI/中英双语由用户裁决。
- 实际游戏资产应拆成背景、角色姿势/动作、道具、UI、数字与字幕。当前8张 Qwen-Image 2.1 样图是**平面风格示意图**，不是可直接用于动画的分层源文件或sprite sheet。
- 一个镜头最多讲一个核心管理动作和一个主梗；其他梗以小气泡/数值作辅梗，避免观众无法读完。

## 节奏与声音方向（仅建议，未制作）

- 以同一办公室的状态变化、弹窗替换、资源上涨/下降驱动节奏；并非禁止硬切，B07发布和B08反应可形成强反差。
- 普通操作给2–4秒读数窗口；高潮梗可短暂停顿后连发，但最终长度取决于发布平台和是否配音。
- 默认候选为轻快芯片音色/游戏经营BGM，加确认、升级、警告三类短UI音效。**这是创作建议，不是对已下载原曲的听辨结论。**

- 当前缺逐帧角色动作序列、最终像素字体文件、可商业使用配乐/音效与目标平台音量规范；本阶段不补剪辑或音频成品。
