## 资产
- 场景底图 12 张、角色精灵表 2 张（25 个角色）、图标表 1 张（12 个图标）、头像表 1 张（6 个头像）：本机 ComfyUI Qwen-Image 2.1 生成，原图与提示词在 `成片工程/底图/`（同名 .txt）。本阶段采用 16 张。
- 底图 BOX 降采样到 480×270 并量化到 64 色，渲染时 4× 最近邻放大；UI 层 960×540，2× 放大。
- 字体：Fusion Pixel 12px 简体（OFL，`成片工程/资产/字体/`）。
- BGM：Fly Me to the Moon（小野丽莎），B 站 BV1F84y1N7tv 音频，`音频/FlyMeToTheMoon-小野丽莎.flac`，取 0–86.5s，结尾 3 秒淡出，核爆瞬间 BGM 压低。歌词时间由 faster-whisper medium 识别（`成片工程/分析/audio.json`）。
- 音效：`pv/audio.py` 程序合成（开罗式确认 / 招聘 / 金币 / 警报 / 盖章 / 欢呼 / 爆炸 / 悲伤长号等 80 处），整体响度 loudnorm −15 LUFS。

## 重新渲染
```bash
cd /mnt/data/Workspace/AI公司PV-开罗风/成片工程
uv run python pv/cut_assets.py   # 仅在底图/精灵表变更时
uv run python pv/audio.py        # 生成 输出/mix.wav
uv run python pv/render.py       # 28 进程并行渲染 → ../成片/AI公司PV_中文版.mp4
uv run python pv/render.py --still 47.8 58.5   # 导出单帧
```
时间轴与文案都在 `pv/scenes.py`，引擎（窗口、按钮、光标、粒子、相机）在 `pv/engine.py`。
